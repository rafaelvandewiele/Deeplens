# DeepLens

**See through AI-generated content.**

DeepLens is a free, open-source tool that analyses images and videos to determine whether they were created by a human or generated by AI. It uses multiple heuristic analysis techniques — no external APIs, no cloud services — everything runs locally on your machine.

---

## Features

| Analysis Layer | What It Detects |
|---|---|
| **Error-Level Analysis (ELA)** | Uniform compression error levels common in synthetic images |
| **Metadata Inspection** | AI-tool signatures in EXIF data, missing camera information |
| **Colour Distribution** | Unusual colour entropy, saturation patterns, channel correlations |
| **Noise Patterns** | Artificial or missing sensor noise, inconsistent noise maps |
| **Edge Consistency** | Edge direction diversity, local density variation |
| **Frequency Spectrum** | Abnormal high/mid/low frequency energy ratios via FFT |
| **Temporal Consistency** *(video)* | Frame-to-frame flickering and inconsistencies |

### Supported Formats

- **Images:** JPEG, PNG, WebP, BMP, TIFF
- **Videos:** MP4, MOV, AVI, WebM, MKV

## Quick Start

### Prerequisites

- Python 3.9+
- pip

### Installation

```bash
git clone https://github.com/YOUR_USERNAME/deeplens.git
cd deeplens
pip install -r requirements.txt
```

### Run

```bash
python run.py
```

Open **http://localhost:8000** in your browser.

---

## How It Works

1. **Upload** an image or video through the web interface.
2. **DeepLens** runs six independent analysis layers on your content.
3. Each layer produces a score from 0 % (likely AI) to 100 % (likely real).
4. A **weighted overall score** is computed and presented with a clear verdict:
   - ✅ **Likely Real**
   - ⚠️ **Inconclusive**
   - 🤖 **Likely AI-Generated**

Analysis visualisations (ELA heat-maps, edge maps, colour histograms, frequency spectra) are provided for each layer so you can inspect the reasoning yourself.

## Disclaimer

DeepLens uses heuristic analysis methods. It is **not** a definitive classifier and should not be used as the sole basis for judging whether content is AI-generated. Results are provided for educational and research purposes.
